# Python Fundamentals Training

Welcome to the Python Fundamentals Training repository! This collection contains 20 hands-on exercises designed to help you learn Python programming from basics to advanced topics.

## 📁 Repository Structure

The repository is organized into two main folders:

- **Jupyter Files** - Contains original Jupyter Notebook files (.ipynb) for interactive learning
- **Python Scripts** - Contains converted Python script files (.py) for standard execution

## 🚀 Getting Started

### Prerequisites

Before running the scripts, make sure you have Python installed on your computer. You'll also need these Python libraries:

- pandas (for data analysis tasks)
- numpy (for numerical operations)
- openpyxl (for Excel file handling)

You can install these using pip:
```bash
pip install pandas numpy openpyxl
```

### How to Use

**Option 1: Using Jupyter Notebooks**
1. Install Jupyter Notebook: `pip install jupyter`
2. Navigate to the "Jupyter Files" folder
3. Run: `jupyter notebook`
4. Open any .ipynb file to interact with the code

**Option 2: Using Python Scripts**
1. Navigate to the "Python Scripts" folder
2. Run any script: `python Task1_HelloWorld.py`

## 📚 Topics Covered

The 20 tasks cover the following Python concepts:

### Basics (Tasks 1-5)
- **Task 1**: Hello World - Learn to print output
- **Task 2**: Variables and Data Types - Understanding how Python stores data
- **Task 3**: Operators - Mathematical and logical operations
- **Task 4**: Control Structures - If/else statements for decision making
- **Task 5**: Loops - For and while loops for repeating actions

### Data Structures (Tasks 6-8)
- **Task 6**: Lists and Tuples - Organizing data in collections
- **Task 7**: Sets and Dictionaries - Advanced data organization
- **Task 8**: String Methods - Working with text data

### Functions (Task 9)
- **Task 9**: Functions - Creating reusable code blocks

### Advanced Topics (Tasks 10-20)
- **Task 10**: Lambda Functions - Quick, anonymous functions
- **Task 11**: File Handling - Reading and writing files
- **Task 12**: Exception Handling - Dealing with errors gracefully
- **Task 13**: Classes and Objects - Object-oriented programming basics
- **Task 14**: Inheritance and Polymorphism - Advanced OOP concepts
- **Task 15**: Encapsulation and Abstraction - Protecting data in classes
- **Task 16**: NumPy - Working with numerical arrays
- **Task 17**: Pandas - Data analysis and manipulation
- **Task 18**: Data Cleaning - Preparing messy data for analysis
- **Task 19**: Filter and Aggregation - Analyzing grouped data
- **Task 20**: Date and Time - Working with temporal data

## 📝 Notes

- Each task includes explanations and examples
- Some tasks use sample data files (CSV format) included in the folders
- The Python Scripts folder contains converted versions that work without Jupyter
- All markdown content from original notebooks has been converted to comments in Python scripts

## 🛠️ Conversion Information

The Jupyter Notebook files were converted to Python scripts using an automated conversion script that:
- Converts markdown cells to comments
- Preserves code cells as executable Python code
- Handles Jupyter-specific commands for standard Python execution

## 📖 Learning Path

We recommend following the tasks in numerical order (1-20) as they build upon each other progressively.

## 💡 Tips for Beginners

1. **Read the comments** - Each script contains helpful comments explaining the code
2. **Experiment** - Try modifying the values to see how the output changes
3. **Don't worry about errors** - Learning involves making and fixing mistakes
4. **Take it slow** - Some concepts take time to understand fully
5. **Practice** - The best way to learn is by doing
